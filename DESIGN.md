# Aperture visual system

Bright classroom daylight and long reading sessions call for a light warm canvas. Restrained aubergine accents identify actions and selection; muted sage and rust communicate results with text labels.

Use OKLCH tinted neutrals, a quiet sidebar, 1px borders, modest rounded corners, generous reading space and compact data rows. Arial/system sans serves headings and controls. Tables use tabular numbers. Headings step from 1.25rem to 2rem; body is 1rem with 1.5 line height.

Desktop uses a 240px sidebar and flexible content. Mobile uses a disclosure navigation and stacked forms. Exam player has a compact top bar, central question and a question index. Native radio buttons remain keyboard accessible. Focus rings are explicit. Transitions last 160ms and honor reduced motion.
